# Music Genome Project × Orelha: features do Pandora para 64 faixas do acervo (2026-09-16)

O site do Pandora bloqueia por região fora dos EUA, mas o Internet Archive guarda cópias das páginas de
música, e nelas as features do Music Genome Project vêm em JSON (`focusTraits`, o texto de "Features of
This Track"). O script `docs/pandora-features.mjs` indexa as páginas arquivadas dos artistas do acervo pelo
CDX do Wayback, casa os títulos com as faixas e extrai as features (preferindo o álbum original às
coletâneas). Resultado: 64 das 236 faixas com features; 114 sem página arquivada; o resto com página mas
sem features. **São as "explicações" que o Pandora mostra ao ouvinte — 6 a 20 genes em texto por música,
sem nota numérica; não são os 450 genes com pontuação.** Servem para conferir direção, não para calibrar.

## Leitura

- Onde o Pandora e o Orelha medem a mesma coisa (modo maior/menor), concordam quase sempre; as divergências
  são os casos ambíguos que o Stephenson prevê (relativas, modos, terça blue) e vão para o KeyDeriver.
- A maior parte dos genes frequentes é de **instrumentação e vocal**, o que reforça F3 (atividade por stem) e
  a aba Genoma manual: harmonia é uma fração pequena do que o MGP anota.
- "extensive vamping", "repetitive melodic phrasing", "basic rock song structures" e "thru composed" são os
  genes de forma que as partes cíclicas do Orelha já aproximam — dá para emitir uma nota DERIVED para eles
  com o que existe (repeats, número de partes, partes sem ciclo).
